This project performs Customer Personality Analysis using Machine Learning to help businesses segment their customer base, understand buying behaviors, and optimize targeted marketing campaigns.📊 Project OverviewUnderstanding customer profiles is essential for targeted marketing. This project processes marketing campaign data, handles missing values and outliers, engineers useful features, and groups customers into distinct clusters using K-Means Clustering.🛠️ Tech Stack & LibrariesPythonPandas & NumPy (Data Manipulation & Cleaning)Matplotlib & Seaborn (Exploratory Data Analysis & Visualizations)Scikit-Learn (Standardization, K-Means Clustering, & Silhouette Score)⚙️ Workflow & StepsData Cleaning:Loads tab-separated dataset (marketing_campaign.csv).Fills missing Income values using the median.Removes outliers (e.g., ages >= 100 and incomes >= $200,000).Feature Engineering:Total_Spending: Aggregates spending across all product categories (Wines, Fruits, Meat, Fish, Sweets, and Gold).Total_Children: Combines Kidhome and Teenhome.Simplified marital status into Living_Status (Partner / Alone) and education levels into Education_Level.Exploratory Data Analysis (EDA):Generates distribution plots for income, product spending breakdowns, success rates of past marketing campaigns, and correlation between income and total spending.Saves visual insights such as income_vs_spending.png.Machine Learning Model (Clustering):Normalizes features (Age, Income, Total_Spending, Total_Children) using StandardScaler.Applies K-Means Clustering ($k=4$) to segment customers into distinct behavioral groups.Model Evaluation:Evaluates clustering performance using the Silhouette Score.Outputs average profiles for each customer segment.# Customer-Personality-Analysis
